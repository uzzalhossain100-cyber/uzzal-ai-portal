🔑 STEP 1: Gemini API Key (AI এর জন্য - আবশ্যক)

কিভাবে পাবেন? aistudio.google.com/app/apikey → Create API Key → Copy → এখানে Paste

☁️ STEP 2: Supabase URL & Anon Key (Cloud এর জন্য - আপনি এখানে আটকেছেন)

এই ২টা ঘরেই আপনার Supabase URL ও Key বসাবেন। Vercel Dashboard এ না, এই Popup এর ভিতরেই!

Supabase → Project Settings → API → Project URL → Copy
Supabase → Project Settings → API → anon public → Reveal → Copy → এখানে Paste (পুরোটা)
